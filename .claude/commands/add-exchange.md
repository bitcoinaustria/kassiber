Read and follow [the exchange playbook](../../skills/kassiber/references/add-exchange.md).
It owns the no-code alternative, intake requirements, confirmation before
implementation, importer touchpoints, and verification workflow.

If the user supplied an exchange name, start or resume that exchange’s spec in
`docs/exchanges/`. Otherwise ask which exchange they want to add. Keep sample
secrets and personal data out of the spec and chat. Only open a PR if requested.
